# Sanitized configuration examples

These files are documentation-only examples for the H1/H2/G11 feature
surface. They are not discovered by the baseline installer. Replace the
example profile roots, service users, unit names, ports, and runtime secret
mounts only after reviewing the complete target deployment.

The examples intentionally use example.com, RFC 5737 addresses, loopback
service endpoints, and generic runtime-only credential paths. They contain no
tokens, remote keys, hashes, live IDs, or backup evidence.
